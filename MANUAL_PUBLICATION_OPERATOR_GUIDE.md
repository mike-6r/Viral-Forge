# Manual Publication Operator Guide

ViralForge never uploads in this workflow. After you upload from the platform app, select **Record Manual Post** in the approved content package and enter the platform, destination/account label, public HTTPS post URL, and notes. The default publication time is now; use the API route when an exact historic time is required.

The record is tied to the brand, project, rendered clip, approved package version, and media asset. A duplicate platform/post URL is rejected. Recording it does not create a provider publishing request.
