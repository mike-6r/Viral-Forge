# Autopilot safety limitations

Autopilot never replaces rights approval, moderation, destination ownership, brand isolation, provider authorization, or the existing review gates. Missing evidence creates a task instead of discarding a source or clip.

TikTok uses the official provider boundary. Draft transfer ends in operator completion; transfer success is not publication. Direct Post is blocked until HTTPS, scope, creator capability, app-review/privacy state, destination ownership, and explicit provider approval are validated. YouTube automated testing remains private or unlisted; public upload needs explicit authorization. Analytics uses official provider APIs only and leaves unavailable metrics null.
