# Subtitle style configuration guide

Subtitle settings belong in the brand content profile and must reference deployment-available fonts. The correction layer does not accept arbitrary style strings, font files, or FFmpeg filters. Until a subtitle renderer control is available and tested, subtitle quality findings result in manual-review recommendations rather than unsafe automatic changes.

Safe-area, line-count, position, outline, background, highlighting, and profanity settings must be rendered by the existing approved renderer before they can become selectable correction actions.
