# Clip revision and comparison guide

Every correction creates a child clip with a root/parent relationship, revision number, and correction-plan reference. The source MP4, source asset, preview grants, inspection history, and prior packages remain historical and intact.

Comparisons only score completed inspection evidence. A missing or failed inspection is **Inconclusive**, never an implied improvement. Selecting the revision only changes the operator-selected clip; it cannot reuse a package for mismatched media or produce a publish request.
