# ViralForge Discord branding guide

The official Discord visual system uses a near-black foundation, coral `#ff4d44`, signal blue `#3ba3ff`, white text, thin-line workflow motifs, and restrained gradients. Use the original PNG files listed in `assets/discord/viralforge/ASSET_MANIFEST.md` for Discord embeds and server thumbnails.

Keep copy competent and useful: explain workflow, rights, review, and support without promising automatic results. Do not include customer data, source media, credentials, private URLs, or operational identifiers in public graphics or embeds.
