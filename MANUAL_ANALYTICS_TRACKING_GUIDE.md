# Manual Analytics Tracking Guide

For each recorded manual post, enter only metrics actually visible to you. Omit unavailable values; they are stored as null, never as zero or estimates. The standard checkpoints are 1h, 6h, 24h, 72h, and 7d. Checkpoints can be completed, skipped, or snoozed with an audit event.

Manual snapshots are included in the brand analytics dashboard as `MANUAL`; existing provider analytics remain separate. ViralForge produces advisory comparisons only and does not change brand settings or publish content.
