# Clip correction operator guide

1. Open a finished clip's **Media Quality** report and inspect the secure preview.
2. Create a correction plan only after a completed inspection. Review the bounded action list and deselect anything that is not appropriate.
3. Submit the plan to see its preview and conflicts. Submission does not render.
4. Select **Confirm Rerender** only after reviewing the exact current plan version. This queues one immutable revision.
5. Open the new secure preview and wait for reinspection. Compare results before choosing **Keep Original** or **Use Revised**.

Using a revised clip does not approve it, generate a content package, schedule it, or publish it. Existing explicit clip, package, rights, moderation, and destination approvals remain required.
