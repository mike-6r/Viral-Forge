# Mobile Clip Download Guide

Open **Download Full Quality** from the approved rendered-clip card in Discord. The private link opens a mobile-safe page; save the MP4 to Files or use the phone share sheet.

The link is only for the one rendered clip, expires quickly, is limited in use, and can be revoked. It is not a preview proxy. If the bot reports `DOWNLOAD_HTTPS_REQUIRED`, configure the existing HTTPS public hostname first; do not use temporary HTTP IP-bootstrap for a phone download.

After the manual upload, return to the approved content package and select **Record Manual Post**.
